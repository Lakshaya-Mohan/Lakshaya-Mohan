## 🚀 Featured Projects

### 🎮 Wavelength
Real-time multiplayer recreation of the Wavelength party game using React, Node.js, Express, and Socket.IO. Implemented WebSocket-based room management, live state synchronization, turn handling, timers, scoring logic, and an interactive spectrum UI for seamless online gameplay.

### 🏡 Nammastay
Full-stack student accommodation platform built with Flask and PostgreSQL, featuring location-based search, smart filters, and interactive maps.

### 🎬 Movie Ticket Booking System
Desktop application built using Python, Tkinter, and SQL for booking movie tickets, managing seat availability, user authentication, and ticket generation.

### 🌐 Network Outlier Detection
Machine learning project for detecting anomalous network traffic using anomaly detection techniques to identify suspicious behavior and potential cyber threats.

### 📊 OBE Attainment System
Web application that automates Outcome-Based Education (OBE) calculations by evaluating CO, PO, and PSO attainment from student assessment data and generating attainment reports.

### 🌬 Wind Turbine Fault Detection
Machine learning model for detecting wind turbine blade defects using vibration signal analysis and ensemble learning techniques.

### 👁 Smart OCR Headband
Raspberry Pi–based wearable device that captures printed text, performs OCR, and converts it to speech to assist visually impaired users.
